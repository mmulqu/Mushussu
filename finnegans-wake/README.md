# Finnegans Wake Reading Project

**Started:** 2026
**Pace:** 1 page per day
**Total Pages:** 628 (standard edition)

## Purpose

A slow, sustained reading of James Joyce's Finnegans Wake—one page at a time—with interpretations, annotations, discoveries, and thematic threads tracked as we go.

## Structure

- Each page gets its own markdown file: `page-001.md`, `page-002.md`, etc.
- Files contain:
  - The page number and book section
  - Key phrases or passages
  - Interpretations and glosses
  - Recurring motifs (HCE, ALP, thunder words, etc.)
  - Cross-references to other pages
  - Personal reflections and questions

## Resources
